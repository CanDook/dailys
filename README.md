# Dailys

- `arise.html` is the page published as the Claude artifact (cloud save through your Claude account, plus on-device storage).
- `index.html`, `manifest.json`, `sw.js`, `icon.svg` are a standalone offline PWA. Host the folder on any static host (e.g. GitHub Pages), open it in Chrome on the phone, then menu > Add to home screen / Install app. This version saves on the device only; use Settings > Copy backup to move progress between the two.
